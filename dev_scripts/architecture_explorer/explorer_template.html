The contract every connector keeps

    Connector family or catalogue?

    Every extension point is one or the other. The four families and four of the five catalogues are built on one kit, core/registry.py (the standard library only); the analysis kinds are a plain dict, since biostats imports nothing of the project. Names and kinds are read from the registries; where each connector runs is written for this page, and checked against what its class declares.

    Catalogues: the kinds that stored data name

    A trace, a rule or a result names its kind by an id that is never renamed; a kind nothing records any more stays, marked legacy (struck through), so that what was stored still reads.
