Cohort Data Exploration

Intuitive, Rapid Exploration for Clinical Cohorts

Designed specifically for observational cohorts, disease registries, and real-world clinical datasets. Move effortlessly from raw, heterogeneous hospital files to structured, analysis-ready patient cohorts with continuous quality monitoring.

01 // INGESTION & PROFILING

Zero-Boilerplate Ingestion & Profile Dataclass

Instantly ingest multi-gigabyte CSV, Parquet, or Excel files with automated encoding discovery, dialect detection, and streaming DuckDB persistence. Generates an immutable DatasetProfile dataclass capturing memory footprint, column archetypes, and value cardinalities.

  • Automated Schema Typing: Resolves date-time variations, discrete ICD codes, and continuous biomarkers without manual type conversions.
  • Zero-Copy Parquet Storage: In-process DuckDB engine guarantees snappy querying and instant column filtering without external database drivers.
  • User Data Isolation: Strict row-level boundaries and segregated working directories per research account for privacy and data governance.
02 // 6-PILLAR HEALTH AUDIT

Automated Health Auditing & Clinical Anomaly Rules

Continuous multi-dimensional cohort validation evaluating Completeness, Uniqueness, Uniformity, and Validity. Define custom boolean clinical masks to immediately isolate biologically impossible or contradictory values.

  • Tri-Method Outlier Isolation: Detects physiological anomalies using IQR bounds, Z-score screening, or unsupervised Isolation Forest scoring.
  • Clinical Anomaly Expressions: Real-time boolean expression evaluations (e.g., Systolic_BP < Diastolic_BP or HbA1c > 20.0) with visual cell highlighting.
  • Signed Audit Certificates: Generates field-by-field completeness scorecards and data health certificates ready for trial review.
03 // MISSINGNESS PATTERNS

Little's MCAR Diagnostics & Pairwise MAR Dependency

Opaque missing data biases epidemiological inference. CMP applies a heuristic permutation test of Little's MCAR alongside pairwise dependency tests to detect whether omissions are missing completely at random or dependent on clinical covariates.

  • Little's MCAR Permutation: Tests mean vector equivalence across missingness patterns (d² ~ χ²) to validate whether complete-case analysis is legitimate.
  • Pairwise MAR Dependency: Evaluates chi-square associations between missing indicators and observed clinical predictors.
  • Interactive Sparsity Matrix: Visual heatmap and dendrogram clustering co-missing variable blocks across longitudinal patient records.
04 // CLINICAL PHENOTYPING

MICE, MissForest & Multidimensional Stratification

Combine flexible multivariate imputation with unsupervised patient stratification. Automatically reduces high-dimensional clinical profiles using FAMD or PCA before clustering into actionable patient sub-phenotypes.

  • Non-Linear Imputation: Chained Random Forest (MissForest) and Predictive Mean Matching (MICE) preserving complex clinical covariance structures.
  • Mixed-Data Phenotyping: Factor Analysis of Mixed Data (FAMD) handles continuous lab panels alongside categorical diagnosis flags.
  • Standard Semantic Ontologies: AI-driven variable renaming mapped directly to UMLS, SNOMED CT, and LOINC clinical terminology.

Epidemiological Decision Engine

Automated Biostatistical Decision Tree & Matrix

CMP eliminates methodological guesswork, human bias, and reviewer skepticism. By rigorously testing sample size, distributional shape, and homoscedasticity, the platform directs researchers to the exact STROBE- and CONSORT-compliant analytical test.

DECISION NODE 01 // NORMALITY & SAMPLE SIZE Screening Pre-Requisite

Distribution Normality Assessment

Evaluates the null hypothesis H0 that clinical continuous measurements are drawn from a normally distributed population prior to selecting between parametric and non-parametric estimators.

IF N < 5,000 AND Shapiro-Wilk p ≥ 0.05 (OR N ≥ 5,000 AND D'Agostino p ≥ 0.05) Parametric Pathway Approved Normal Gaussian distribution confirmed. Proceed to variance homogeneity check (Node 02). Computes mean ± standard deviation. Effect Size: Cohen's d or Hedges' g
IF Normality p < 0.05 OR Absolute Skewness |s| > 1.5 Non-Parametric Pathway Enforced Significant distributional skew or heavy tails detected. Routes directly to rank-sum tests (Mann-Whitney U, Kruskal-Wallis). Reports median and IQR. Effect Size: Rank-Biserial r or Cliff's Δ
DECISION NODE 02 // VARIANCE HOMOGENEITY Homoscedasticity Check

Levene Test for Equality of Variances

Standard Student's t-test and Fisher's ANOVA assume equal population variances (σ1² = σ2² = ... = σk²). Violations drastically inflate false positive (Type I) rates in clinical trials.

IF Levene's Test p ≥ 0.05 (Equal Variances Confirmed) Student's t-Test / One-Way ANOVA Equal variance assumption satisfied. Post-hoc testing utilizes Tukey's Honestly Significant Difference (HSD) with pooled standard error. Eta-squared (η²) & Omega-squared (ω²)
IF Levene's Test p < 0.05 (Heteroscedasticity Detected) Welch's t-Test / Welch's ANOVA Applies Welch-Satterthwaite degrees of freedom correction. Post-hoc pairwise evaluations automatically execute Games-Howell adjustments. Welch-adjusted F-statistic & Hedges' g
DECISION NODE 03 // MULTI-GROUP COHORT STRATA ≥ 3 Groups Comparison

Multi-Arm Stratification & False Discovery Correction

Evaluates continuous biomarkers across three or more trial arms or disease severity tiers with multiple testing control.

IF Normality & Homoscedasticity Met (≥ 3 Groups) One-Way ANOVA + Tukey HSD Calculates between-group vs within-group variance ratio (F-statistic). Reports omnibus p-value followed by pairwise Tukey HSD intervals. η² = SS_between / SS_total
IF Normality Rejected or Ordinal Severity Scale Kruskal-Wallis + Dunn's FDR Post-Hoc Calculates H-statistic based on average rank sums across cohorts. Pairwise post-hoc comparisons apply Benjamini-Hochberg False Discovery Rate. ε² = (H - k + 1) / (N - k)
DECISION NODE 04 // BASELINE CONFOUNDING Covariate Adjustment

Multivariate ANCOVA with Slope Homogeneity Diagnostic

Tests treatment arm efficacy while adjusting for baseline continuous covariates (e.g., baseline HbA1c, age, eGFR). Automatically validates whether regression slopes are parallel across study arms before reporting adjusted means.

IF Group × Covariate Interaction F p ≥ 0.05 Homogeneous Slopes Validated → Standard ANCOVA Parallel slopes confirmed. Covariate-adjusted marginal means and 95% confidence intervals are reported alongside adjusted F-statistic. Partial η² = SS_effect / (SS_effect + SS_error)
IF Interaction F p < 0.05 (Violation: Non-Parallel Slopes) Interaction Alert → Johnson-Neyman Floodlight Standard ANCOVA is biased because treatment effect varies as a function of the baseline covariate. Flags model and maps regions of significance. Moderation Analysis Enforced
DECISION NODE 05 // 2×2 CONTINGENCY & RARE OUTCOMES Categorical Epidemiology

Relative Risk (RR) vs Odds Ratio (OR) with Zero-Cell Correction

Differentiates prospective longitudinal cohort incidence from retrospective case-control odds, applying continuity corrections when rare adverse events occur in only one study arm.

IF Prospective Cohort / RCT (Expected Cells ≥ 5) Relative Risk (RR) & Pearson χ² Computes cumulative incidence ratio [a/(a+b)] / [c/(c+d)], Risk Difference (RD), Number Needed to Treat (NNT), and Taylor series 95% CIs. RR = Incidence_exposed / Incidence_unexposed
IF Zero-Cell Event (a, b, c, or d = 0) OR Case-Control Design Haldane-Anscombe (+0.5) Odds Ratio & Fisher's Exact Adds +0.5 to all contingency cells to eliminate singular log-odds. Validates that OR ≈ RR only when disease outcome prevalence < 10%. OR_ha = [(a+0.5)(d+0.5)] / [(b+0.5)(c+0.5)]
DECISION NODE 06 // DIAGNOSTIC SCREENING Biomarker Benchmarking

Diagnostic Test Accuracy & Cutoff Optimization

Evaluates clinical screening tools, biomarker cutoffs, and diagnostic assays against definitive clinical ground truth.

IF Continuous Biomarker Assay vs Binary Disease Status Empirical ROC AUC Curve & DeLong 95% CIs Computes non-parametric Area Under the ROC Curve with DeLong asymptotic variance estimation. Evaluates discrimination power. Diagnostic Odds Ratio: DOR = (Sens/(1-Sens)) / ((1-Spec)/Spec)
IF Optimal Clinical Decision Threshold Required Youden's Index J Cutoff Optimization Selects the threshold maximizing J = Sensitivity + Specificity - 1. Reports positive/negative likelihood ratios (LR+, LR-) and predictive values. J_max = max(Sensitivity_t + Specificity_t - 1)

Quantitative LLM Validation

Scientific RAGAS Framework & Source Provenance

Clinical decision support demands verifiable, evidence-based truth—not plausible hallucination. CMP integrates the scientific RAGAS framework alongside a three-tier attribution mechanism to audit every generated answer against verbatim peer-reviewed text.

RAGAS METRIC 01

Faithfulness (Factual Groundedness)

Faithfulness = |Claims Supported by Context| / |Total Claims in Answer| ∈ [0, 10]

An LLM-as-judge parser extracts every atomic factual statement from the generated clinical response and verifies each against the retrieved document chunks. Any assertion lacking direct textual evidence is flagged as an unsupported hallucination.

RAGAS METRIC 02

Context Relevance (Signal-to-Noise)

Context Relevance = |Relevant Sentences in Context| / |Total Sentences in Chunks| ∈ [0, 10]

Evaluates ChromaDB vector retrieval efficiency. Quantifies whether retrieved document passages contain actionable clinical evidence or extraneous background noise, preventing prompt context bloat and distraction.

RAGAS METRIC 03

Answer Relevance (Semantic Fidelity)

Answer Relevance = Cosine_Sim(Embedding(q), Embedding(q_gen)) ∈ [0, 10]

Reversely generates synthetic clinical questions from the generated response and computes cosine embedding similarity against the original investigator query. Penalizes evasive, redundant, or non-pertinent replies.

Three-Tier Provenance & Evidence Attribution

Every statement generated by the CMP Document Insight engine is classified into an auditable evidence tier with complete document coordinates (Document Name, Page Number, Chunk ID, and Cosine Similarity).

TIER 1 // VERBATIM EXTRACTION

Direct Document Citation

Cosine similarity ≥ 0.85. The claim is a direct quote or near-verbatim extract from the indexed protocol, clinical guideline, or paper. Displays exact document name, page number, and highlighted source paragraph.

TIER 2 // MULTI-CHUNK SYNTHESIS

Cross-Document Evidence Synthesis

Cosine similarity between 0.70 and 0.85. The claim synthesizes clinical evidence spanning multiple sections or trials. Displays weighted ranking across all contributing source chunks.

TIER 3 // PARAMETRIC MODEL PRIOR

Pretrained Foundation Prior

Cosine similarity < 0.70. Explicitly flags when an LLM utilizes general background medical knowledge not directly verified in local indexed files, alerting researchers to check external literature.

System Design

Clean, Modular Layered Architecture

Strict separation of concerns across presentation, domain calculation, orchestration, and persistence layers.

1. Presentation Layer

Streamlit 1.65+ multi-page application with responsive layouts, accessible typography, Plotly clinical graphics, and zero unprofessional emoji noise.

2. Domain & Computation

Immutable DatasetProfile dataclass, multi-method outlier isolation, MICE and MissForest imputation pipelines, and biostatistical engines.

3. Orchestration & Pipeline Replay

TransformationManager lineage logger, reproduction_manager headless/UI pipeline replay engine, and TraceDocumenter Word (.docx) audit dossier generator.

4. Persistence Layer

5. RAG & Intelligence

Provider-agnostic connector factory supporting local Ollama, Google Gemini, OpenAI, and Mistral with Pydantic response validation and schema fallback.

6. Security & Isolation

Role-based user authorization with mandatory administrative account approval, isolated dataset directories, and air-gapped deployment capability.
