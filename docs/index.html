Columnar Parquet Persistence & Automated Versioning

DuckDB powers in-process columnar transformations and exports datasets directly to versioned Parquet files. Zero connection lock-in, transactional stability, and multi-user data isolation.

  • Atomic Versioning: Saves version snapshots (e.g. cardio_cohort_v1, v2) with metadata.
  • Ultra-Fast Statistics Cache: Pre-calculates numerical and categorical aggregates in Parquet format.
  • Isolated User Namespaces: Row-level privacy and directory boundaries enforced per research account. 
# Native DuckDB Parquet Persistence with Versioning
from manage.db_manager import DBManager

db = DBManager()

# Persist snapshot with automatic version increment
ok, msg, version_id = db.save_dataset(
    df=clinical_df, 
    base_name="diabetic_cohort", 
    username="dr_smith"
)
print(version_id)  # -> "dr_smith_diabetic_cohort_v2"

# Reload dataset with zero-copy DuckDB execution
df_loaded, msg = db.load_dataset("diabetic_cohort_v2")

Statistically Rigorous Epidemiological Inference

Automates the selection between parametric and non-parametric tests while computing clinical effect sizes, adjusting for covariates (ANCOVA), and diagnosing missingness patterns.

  • 2x2 Contingency Epidemiology: Relative Risk, Odds Ratio with Haldane-Anscombe zero-cell correction.
  • Effect Sizes: Cohen's d, Hedges' g (small-sample correction), Eta-squared (η²), and Omega-squared (ω²).
  • Missingness Diagnostics: Little's MCAR permutation test with pairwise MAR dependency tests. 
# Epidemiological 2x2 Trial & Effect Size Analysis
from explore.epidemiology_stats import (
    calculate_2x2_epidemiology, 
    calculate_effect_size
)

# Cohort Risk Ratio with small-sample correction
epi_res = calculate_2x2_epidemiology(
    table_df=table_2x2,
    study_type="cohort",
    correction="haldane_anscombe"
)
print(f"RR: {epi_res['relative_risk']} (CI: {epi_res['rr_ci_lower']}-{epi_res['rr_ci_upper']})")

# Hedges' g with exact unbiased gamma approximation
eff = calculate_effect_size(group_a, group_b, method="hedges_g")
print(f"Hedges' g: {eff['effect_size']} ({eff['magnitude']})")

Quality Scoring, Audit Trails & Deterministic Reproducibility

Evaluate cohort health across completeness, uniqueness, consistency, and clinical rules while ensuring complete workflow reproducibility. Rather than producing only static documentation, CMP captures deterministic execution traces that re-execute entire multi-step transformation pipelines (enrichment joins, MICE/MissForest imputations, feature scaling), alongside generating signed Word (.docx) audit dossiers.

  • Multi-Dimensional Scoring: Completeness, Uniqueness, Uniformity, and IQR / ML Outlier Validity.
  • Clinical Anomaly Rules: Evaluates boolean mask expressions to highlight biologically implausible values.
  • End-to-End Pipeline Reproduction: Deterministic replay engine re-executes complete multi-step transformations (enrichment joins, MICE/MissForest imputers, mathematical transforms) headless or interactively to reproduce exact analytical datasets.
  • Signed Word (.docx) Dossiers: Auto-generates audit certificates and transformation parameter manifests ready for peer review. 
# 1. Multi-Dimensional Quality Audit
from explore.data_quality_auditor import DataQualityAuditor

Methodological Excellence

Built-In Clinical Biostatistics Suite

Automated decision engines adhering to STROBE and CONSORT reporting guidelines.

01 // HYPOTHESIS TESTING

Parametric & Non-Parametric

Shapiro-Wilk and D'Agostino normality screening routes data between Student's t-test, Welch's t-test (unequal variances), Mann-Whitney U, One-Way ANOVA, Kruskal-Wallis, Welch's ANOVA, and Games-Howell post-hoc tests.

02 // 2×2 CONTINGENCY

2x2 Cohort & Case-Control

Relative Risk (RR), Odds Ratio (OR), and Risk Difference (RD) calculations featuring Haldane-Anscombe zero-cell continuity corrections (+0.5) to prevent infinite odds ratios in rare clinical outcomes.

03 // CLINICAL EFFECT SIZES

Clinical Effect Sizes

Computes Cohen's d, Hedges' g (with exact unbiased gamma factor for small cohort sizes), Eta-squared (η²), and Omega-squared (ω²) to evaluate medical impact beyond statistical significance.

04 // MISSINGNESS DIAGNOSTICS

Little's MCAR Diagnostics

Heuristic Little's MCAR missingness permutation test combined with bivariate MAR tests. Identifies whether variable omissions are completely at random or dependent on clinical covariates.

05 // MULTIVARIATE COVARIANCE

Multivariate ANCOVA

Evaluates treatment efficacy while adjusting for continuous clinical covariates. Automatically validates the assumption of homogeneity of regression slopes before reporting adjusted means.

06 // DIAGNOSTIC ACCURACY

Diagnostic Test Accuracy

Complete screening benchmark: Sensitivity, Specificity, Positive/Negative Predictive Value (PPV/NPV), Youden's Index J, Positive/Negative Likelihood Ratios (LR+, LR-), and ROC AUC curve profiling.

System Design

Clean, Modular Layered Architecture

Strict separation of concerns across presentation, domain calculation, orchestration, and persistence layers.

1. Presentation Layer

Streamlit 1.65+ multi-page application with responsive layouts, accessible typography, Plotly clinical graphics, and zero unprofessional emoji noise.

2. Domain & Computation

Immutable DatasetProfile dataclass, multi-method outlier isolation, MICE and MissForest imputation pipelines, and biostatistical engines.

3. Orchestration & Pipeline Replay

TransformationManager lineage logger, reproduction_manager headless/UI pipeline replay engine, and TraceDocumenter Word (.docx) audit dossier generator.

4. Persistence Layer

Embedded DuckDB 1.5+ Parquet storage with versioning, bcrypt credential verification, and on-demand connection cycling preventing Windows file locks.

5. RAG & Intelligence

Provider-agnostic connector factory supporting local Ollama, Google Gemini, OpenAI, and Mistral with Pydantic response validation and schema fallback.

6. Security & Isolation

Role-based user authorization with mandatory administrative account approval, isolated dataset directories, and air-gapped deployment capability.

Install in Seconds

Run locally with UV or Pip, or deploy into production with Docker. 

# 1. Clone the repository
git clone https://github.com/KarimELMERNISSI/Cohort-Monitoring-Package.git
cd Cohort-Monitoring-Package

# 2. Sync virtual environment and lockfile
uv sync

# 3. Launch the platform
uv run streamlit run main.py
# 1. Clone repository
git clone https://github.com/KarimELMERNISSI/Cohort-Monitoring-Package.git
cd Cohort-Monitoring-Package

# 2. Create Python 3.14+ environment
python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate

# 3. Install packages & start
pip install -r requirements.txt
streamlit run main.py
# Build container image
docker build -t cohort-monitoring .

# Run container with persistent data volume
docker run -d \
  -p 8501:8501 \
  -v $(pwd)/data:/app/data \
  --name cohort-platform \
  cohort-monitoring
# Start services in detached mode
docker compose up -d

# Monitor running container logs
docker compose logs -f
