# ⚙️ Configuration Editor

## Overview

The **Configuration Editor** allows you to modify the global behavior of the application without touching the code. You can define outlier rules, computed columns, statistical test parameters, and file paths.

## Key Features

### 1. 🎭 Mask Families

Define reusable filters (masks) to subgroup your data.

* **Numeric Masks**: e.g., "Age > 65".
* **Expression Masks**: e.g., "Status == 'Active'".

### 2. 🧮 Computed Features

Define new variables derived from existing ones.

* **Expression**: Write Python-like expressions (e.g., `df['Weight'] / (df['Height']**2)`).
* **Simplified Mode**: Supports natural writing like `Weight / Height^2`.

### 3. 📏 Measurement Conversions

Automate unit conversions.

* Define source and target columns (e.g., `Weight_lb` -> `Weight_kg`).
* Set a conversion rate.

### 4. 📊 Statistical Tests

Pre-configure the hypothesis tests you want to run repeatedly.

* **Test Type**: Select T-test, ANOVA, Kruskal-Wallis, etc.
* **Groups**: Define which groups to compare using your Mask Families.

### 5. 🛠️ General Settings

* **Thresholds**: Adjust global sensitivity for Z-Scores (outliers), IQR, etc.
* **Output Formats**: Toggle which file formats (CSV, Excel, PDF) are generated by the app.

## Usage Guide

1. **Load/Create**: Start from scratch or load an existing `config.json`.
2. **Edit Tabs**: Navigate through the tabs to add/remove rules.
3. **Download**: Click **Download Configuration File** to save your changes as a JSON file. Use this file in your project root or `config/` folder.

## Technical Details

* **File**: `app_pages/config_form.py`
* **Format**: JSON.
